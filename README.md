# Refatoração e Aplicação de Clean Code em Python

Atividade avaliativa da disciplina de **Design Patterns e Clean Code**, com o objetivo de refatorar um código legado em Python aplicando boas práticas de **Clean Code**, sem alterar o resultado esperado do sistema.

##  Objetivo

Melhorar a qualidade, legibilidade, manutenção e confiabilidade do código por meio dos seguintes desafios:

* **A — Nomenclatura Significativa e Estilo (PEP 8)**
* **B — Type Annotations e Docstrings**
* **C — Comentários Úteis vs. Desnecessários**
* **D — Tratamento de Exceções e Validação Profissional**

##  Refatorações Aplicadas

O código legado será refatorado seguindo os requisitos definidos na atividade:

* Utilização de nomes significativos e convenções **PEP 8**;
* Substituição de valores mágicos por constantes;
* Inclusão de **Type Annotations**;
* Criação de **Docstrings**;
* Remoção de comentários redundantes;
* Utilização de comentários apenas quando necessários para explicar decisões;
* Validação adequada dos dados;
* Uso de exceções específicas com `raise`;
* Tratamento de erros como `ValueError` e `KeyError`;
* Utilização adequada de `try`, `except`, `else` e `finally`.

##  Resultado Esperado

Ao final da refatoração, o código deverá manter seu comportamento esperado, porém apresentar maior **clareza, consistência, segurança e facilidade de manutenção**, seguindo os princípios de Clean Code.
